# Data Catalog

Catalog reviewed 27 October 2026. No bulk source dataset was downloaded. Provider records are fetched on demand and cached in API memory for five minutes.

| Dataset / API               | Source and hazards                                                                                                              | Format and fields used                                                                                                       | Access, attribution, update, limitations                                                                                                                                                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| USGS FDSN event query       | [USGS Earthquake Hazards Program](https://earthquake.usgs.gov/fdsnws/event/1/); earthquakes                                     | GeoJSON features; source ID, place, magnitude, event time, updated time, coordinates/depth, details URL                      | Public, no key. Queries are bounded to the selected date range and capped at 100 events in this app. Availability is provider-controlled. Link each event to USGS. Magnitude does not determine local damage.                                      |
| GDACS event search          | [GDACS API](https://www.gdacs.org/gdacsapi/swagger/index.html); earthquake, tropical cyclone, flood, volcano, drought, wildfire | GeoJSON features; event ID/type, name, alert level, description, dates, coordinates and source/report URL where supplied     | No key documented in quick start; first 100 recent records fetched, 30-day window. Acknowledge “Global Disaster Awareness and Coordination System, GDACS”; consult current terms/disclaimer. GDACS levels are not local government warning levels. |
| Open-Meteo Weather Forecast | [Forecast API docs](https://open-meteo.com/en/docs); temperature, precipitation and weather context                             | JSON current values and daily min/max; resolved place, timezone, forecast timestamps                                         | No key used in the configured public endpoint. Forecast horizon is 5 days in this app; models vary by location. Show as forecast context, not warning. Verify terms and attribution requirements before commercial deployment.                     |
| Open-Meteo Air Quality      | [Air Quality API docs](https://open-meteo.com/en/docs/air-quality-api); PM10, PM2.5, ozone                                      | JSON hourly model values and European AQI if returned                                                                        | No key used here. Air-quality model output has spatial/temporal limitations. The UI avoids presenting an India-specific health index and explicitly says it is not a health alert.                                                                 |
| NASA FIRMS                  | [Active Fire Data](https://firms.modaps.eosdis.nasa.gov/content/active_fire/); satellite fire detections                        | Not yet integrated; source catalogs product formats including CSV, KML, shapefile, and services                              | Earthdata registration / MAP key needed for API usage. NRT product latency/replacement caveats apply. App reports credential requirement, does not fake fire results. Credit NASA FIRMS when enabled.                                              |
| NDMA SACHET public content  | [Do's and Don'ts](https://sachet.ndma.gov.in/DosDont); multiple hazard guidance                                                 | Human-readable website; not imported                                                                                         | Linked for current India-specific public guidance. No supported machine-readable feed was verified; not treated as live API data.                                                                                                                  |
| Curated learning material   | Project-authored structured records in `apps/api/src/data/curriculum.js`; earthquake, flood, fire, heat                         | JavaScript object schema: objectives implied by summaries, audience level, minutes, lesson steps, quiz options and citations | Educational content, not incident data. Source URL per module. Reviewed against linked NIDM/NDMA/PIB guidance at implementation; local review required before institutional adoption.                                                              |
| Curated simulations         | Project-authored structured decision steps in `apps/api/src/data/curriculum.js`; earthquake, fire, flood                        | Scenario and decision-choice records; scores computed server-side                                                            | Always labelled educational simulation. Not forecasts or emergency messages. Each scenario links to a source.                                                                                                                                      |

No data.gov.in dataset has been acquired or integrated yet. No campus dataset, student geolocation, alert subscription, or identifiable learner analytics are exposed publicly.
