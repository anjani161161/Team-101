# Research Notes

Research checked on 27 October 2026. This is a software implementation informed by public guidance; it is not a building audit, statutory compliance determination, official warning service, or substitute for local emergency plans.

## Findings and product decisions

- The Ministry of Education's 2021 school safety guidance is advisory and the Ministry asks States and Union Territories to implement it with local additions as needed. The 23 August 2024 PIB release describes preventive education, stakeholder accountability, reporting, support and counselling, accessibility, and a safe school environment. The app therefore treats institutional records as locally owned working plans and does not claim certification.
- NIDM describes school safety as including safe facilities, awareness, communications, preparedness plans, capacity building, rehearsals, and mock drills. The app includes learning, editable preparedness checklists, and drill debrief workflows, while leaving building safety decisions to qualified authorities.
- UNDRR's publication page for the 2017 Comprehensive School Safety Framework explicitly links the 2022–2030 version. UNDRR describes the newer framework as guidance for safe, equitable, continuous access to quality education. The implementation uses its multi-hazard, learning-continuity framing rather than treating a weather dashboard as the product.
- UNDRR's school emergency guidance describes a preparedness committee, a plan, assigned responsibilities, and exercises. It dates from 2010, so it is linked as process guidance, not represented as the newest policy.
- Hazard observations, modelled forecasts, institution records, and educational simulations are different data classes. The UI labels the latter as simulations and reports provider, freshness, and original-source links for observations.
- For Indian use, hazard-specific directions should be localized to the relevant State/UT and current competent authority. The SACHET portal lists hazard guidance in multiple Indian languages. Static general lessons are therefore deliberately qualified by local plans and authority instructions.
- No fake live events, institution, learner metrics, or partnerships are seeded. Curriculum examples are curated educational content. MongoDB stores real user progress and institution-entered records when configured.

## Data-source comparison

| Provider               | Coverage and type                                   | Credentials / freshness                                                         | Current use and limitations                                                                                                                                                                                  |
| ---------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| USGS                   | Global earthquake observations in GeoJSON           | Public feed, no key; all-day feed updated by provider                           | Live API adapter; event magnitude does not imply local impacts. Provider uptime is outside app control.                                                                                                      |
| GDACS                  | Global multi-hazard event records/alerts in GeoJSON | Search API, no key documented; provider updates events                          | Live API adapter filtered by recent 30-day window; up to 100 events fetched per provider page and only the first page is used. GDACS alert levels are not campus risk ratings or Indian government warnings. |
| Open-Meteo Weather     | Location-based current model output and forecast    | Public endpoint used without a key; model update timing varies                  | Geocodes a text query and provides current values plus 5-day daily high/low forecast. A general forecast is not a warning. Review current service terms for commercial deployments.                          |
| Open-Meteo Air Quality | Modelled pollutant forecast                         | Public endpoint used without a key; model timing and geographic resolution vary | Displays a PM2.5 value with explicit “not a health alert” wording. European AQI is not an India-specific health standard.                                                                                    |
| NASA FIRMS             | Satellite active-fire detections                    | Earthdata registration and FIRMS MAP key for API access                         | Not integrated in this version. The API indicates the provider is credential-gated and gives setup instructions rather than simulating success.                                                              |
| NDMA SACHET            | India-specific public hazard guidance and alerts    | Website access; no machine-readable interface validated here                    | Linked as authoritative public guidance; no automated warning ingestion is claimed.                                                                                                                          |

The web research tools could not retrieve the MoE PDF, NDMA policy PDF, NDMA homepage, or GDACS Swagger body in the initial direct open. The PIB corroboration, NIDM portal, UNDRR publication metadata, USGS API documentation, NASA FIRMS page, Open-Meteo documentation, and GDACS official quick-start PDF were accessible. No bulk dataset was downloaded, and no historical dataset is bundled.

## Comparable workflows reviewed

NIDM's school safety material and the UNDRR preparedness note emphasize plans, clear responsibilities, accessible preparation, and practice. NDMA SACHET organizes guidance by hazard and language. USGS recommends real-time GeoJSON feeds for display, while GDACS publishes searchable geospatial multi-hazard data and a source-acknowledgement request. These informed the compact source-labelled incident cards, map, provider state, reusable learning/scenario patterns, institution-owned records, and separation between observation and instruction. No portal UI or wording was copied as an interface template.

## Known research limitations

- The Ministry PDF and NDMA policy PDF were not successfully downloaded during research. Links are retained for verification by project maintainers.
- No local State Disaster Management Authority machine-readable warning feed was validated. SACHET remains a source link, not a live warning integration.
- Open-Meteo model provenance and commercial terms depend on the current provider terms and model/location; review those terms before production use.
- GDACS API terms request acknowledgement and include a disclaimer. This project links attribution and does not publish provider data as its own warning.
