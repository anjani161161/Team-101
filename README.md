# AtmosWatch 🌦️

## Global Weather and Disaster Management System

AtmosWatch is a comprehensive web-based platform designed to provide real-time weather intelligence, disaster monitoring, and preparedness information across the globe. Built with modern web technologies, it offers users a responsive dashboard to track weather conditions, air quality, natural disasters, and emergency preparedness resources.

![AtmosWatch Logo](https://via.placeholder.com/150x50?text=AtmosWatch) <!-- Replace with actual logo if available -->

## 🚀 Features

### Core Functionality
- **Real-time Weather Monitoring**: Search any location worldwide and get current weather conditions
- **5-Day Weather Forecast**: Detailed forecast with temperature trends and weather patterns
- **Air Quality Index**: Comprehensive air quality monitoring with PM2.5, PM10, and O3 levels
- **Live Disaster Tracking**: Real-time monitoring of earthquakes, wildfires, and severe storms

### Disaster Management Center
- **Earthquake Monitoring**: Global earthquake activity with magnitude and location data
- **Wildfire Tracking**: Active wildfire incidents with impact assessment
- **Storm Surveillance**: Severe weather events and storm tracking
- **Extended Coverage**: Additional hazards including volcanoes, landslides, and drought monitoring

### User Experience
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **User Authentication**: Secure login and signup system
- **Interactive Dashboard**: Intuitive navigation with scroll progress indicator
- **Data Visualization**: Clean, modern UI with weather icons and status badges

## 🛠️ Technologies Used

### Frontend
- **HTML5**: Semantic markup and structure
- **CSS3**: Custom styling with modern design principles
- **JavaScript (ES6+)**: Client-side logic and API integration

### APIs & Services
- **OpenWeatherMap API**: Weather data, forecasts, and air quality information
- **Natural Disaster APIs**: Earthquake, wildfire, and storm data feeds

### Development Tools
- **Git**: Version control
- **GitHub**: Repository hosting and collaboration

## 📋 Prerequisites

Before running this project, ensure you have:
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for API calls
- Valid OpenWeatherMap API key

## 🔧 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/anjani161161/Team-101.git
   cd Team-101
   ```

2. **Open in browser**
   - Open `index.html` in your web browser
   - For full functionality, serve via a local server (recommended)

3. **API Configuration**
   - Obtain an API key from [OpenWeatherMap](https://openweathermap.org/api)
   - Update the `WEATHER_API_KEY` in `app.js` with your key

## 🎯 Usage

### Getting Started
1. **Sign Up**: Create a new account using the signup page
2. **Login**: Access the dashboard with your credentials
3. **Explore Weather**: Search for any location or use geolocation
4. **Monitor Disasters**: Navigate to the Disaster Management Center

### Navigation
- **Weather Explorer**: Main dashboard with current conditions and forecast
- **Global Watch**: Overview of worldwide disaster activity
- **Disaster Management**: Detailed incident tracking and management
- **Preparedness**: Emergency preparedness resources and guides
